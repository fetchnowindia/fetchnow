# FetchNow All-in-One MVP

One starter containing the complete product flow in one project:
Customer → Request → Fare → Order
Partner → Registration → Accept order
Customer ↔ Partner → Status updates
Admin → Dashboard
Maps → Location fields + map integration placeholder
Payments → Payment state + checkout integration placeholder
Responsive → Customer, partner and admin views

Run:
1. Install Node.js 18+
2. `npm install`
3. Copy `.env.example` to `.env`
4. `npm start`
5. Open http://localhost:3000

This is a functional MVP foundation. Real Google Maps GPS, payment-provider checkout,
SMS/push, production authentication and cloud hosting require provider credentials and
server-side integration; placeholders are clearly marked in the app.
